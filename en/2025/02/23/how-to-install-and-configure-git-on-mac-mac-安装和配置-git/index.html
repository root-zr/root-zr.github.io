How to Install and Configure Git on Mac | Mac 安装和配置 git

这篇博客介绍在 macbook 上安装和配置 git。

安装 Git #

macOS 通常预装了 Git，但可能不是最新版本。你可以使用 Homebrew 安装或更新 Git：

brew install git

如果尚未安装 Homebrew，则需要先安装它：

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

有时 DNS 解析问题会导致无法访问 GitHub。可以通过下面的方式规避。

  1. 尝试修改 hosts 文件：

打开终端，输入以下命令编辑 hosts 文件：

sudo vim /etc/hosts

在文件末尾添加以下内容：

185.199.108.133 raw.githubusercontent.com

保存并退出,重新运行安装命令。

2.使用镜像源

如果直接访问 GitHub 有问题，可以使用国内的镜像源安装 Homebrew, 运行以下命令：

/bin/zsh -c "$(curl -fsSL https://gitee.com/cunkai/HomebrewCN/raw/master/Homebrew.sh)"

按照提示选择镜像源并完成安装。

验证安装 #

打开终端，输入以下命令检查 Git 是否安装成功：

git --version

配置 Git #

安装完成后，需要配置用户名和邮箱，这些信息会用于提交记录。

设置用户名：

git config --global user.name "你的用户名"

设置邮箱：

git config --global user.email "你的邮箱"

检查配置：

git config --list

生成 SSH 密钥 #

如果你需要通过 SSH 连接到远程仓库（如 GitHub），可以生成 SSH 密钥：

ssh-keygen -t ed25519 -C "你的邮箱"
  • 按回车使用默认路径。
  • 设置密码（可选）。

查看公钥：

cat ~/.ssh/id_ed25519.pub

将公钥复制到远程仓库的 SSH 设置中（如 GitHub 的 Settings > SSH and GPG keys）。
